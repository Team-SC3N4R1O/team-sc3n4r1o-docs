# 프로젝트 개요

### 프로젝트 소개

Team SC3N4R1O는 실제 침해사고 사례를 기반으로 공격 흐름을 분석하고, 이를 AWS 기반의 통제된 실습 환경에서 안전하게 재현하는 프로젝트를 진행했습니다.

본 프로젝트는 단순히 침해사고 사례를 조사하는 데 그치지 않고, 공격 과정에서 어떤 로그와 흔적이 남는지, 보안 담당자가 이를 어떻게 탐지하고 대응할 수 있는  지를 확인하고 학습하는 데 초점을 두었습니다.

이를 위해 침해사고 시나리오 분석, AWS 재현 환경 구축, Red Team 공격 재현, 보안 솔루션 조합 테스트, 배치 암호화 구현, AI 기반 로그 분석 파이프라인을 하나의 흐름으로 연결했습니다.

{% hint style="info" %}
본 프로젝트는 실제 공격 수행을 목적으로 하지 않으며, 침해사고 대응 과정을 이해하기 위한 교육·연구 목적의 안전한 재현 실습입니다.
{% endhint %}

### 프로젝트 목표

본 프로젝트의 핵심 목표는 실제 침해사고를 바탕으로 공격부터 탐지, 분석, 대응까지 이어지는 전체 과정을 직접 재현하고 검증하는 것입니다.

재현된 공격 흐름을 기준으로 단계별로 어떤 보안 로그가 생성되는지, 어떤 보안 통제가 먼저 탐지하는지, 탐지 공백은 어디에서 발생하는지를 확인하는 데 중점을 두었습니다.

### 전체 수행 흐름

1. 실제 침해사고 사례 조사 및 비교
2. 워밍업 사례를 통한 Terraform·AWS 환경 구축 및 로그 분석 기초 학습
3. 롯데카드 침해사고 기반 메인 시나리오 선정
4. AWS 기반 침해사고 재현 환경 구축
5. Red Team 공격 흐름 안전 재현
6. WAF / Host Detection / Network Detection 조합별 실험
7. 배치 암호화 적용 전후 데이터 반출 상태 비교
8. AI 기반 로그 분석·대응 지원 파이프라인 구축

### 핵심 검증 영역

공격 재현 · 보안 통제 조합 실험 · 배치 암호화 · AI 로그 분석 파이프라인

### 프로젝트 방향성

본 프로젝트는 실제 침해사고에서 확인된 공격 패턴을 AWS 기반의 통제된 환경에 재구성하고, **공격·탐지·분석·대응으로 이어지는 전체 과정을 직접 구현하고 검증**하는 것을 목표로 했습니다.

먼저 **내부 관계자의 유효 인증정보 악용에 따른 대량 정보 유출 사례**를 워밍업 시나리오로 구성하여 Terraform 기반 AWS 환경 구축, 로그 수집 구조, 정상 접근과 이상 접근의 차이를 학습했습니다.

이후 외부 노출 WAS 침해를 시작으로 웹셸, 내부 탐색, 데이터 수집 및 반출까지 이어지는 메인 시나리오를 구축하고 다음 단계로 확장했습니다.

* WAF·Host·Network 보안 통제 조합별 탐지 효과 비교
* MASS·LOW\_SLOW 데이터 반출 패턴 실험
* 배치 암호화 시점에 따른 데이터 보호 상태 검증
* `run_id` 기반 다중 로그 및 Ground Truth 연계
* AI 기반 침해사고 로그 분석·대응 지원 파이프라인 구축

이를 통해 개별 기술을 단순히 구현하는 데 그치지 않고, **하나의 침해사고 흐름에서 각 보안 통제가 어떤 증적을 남기고 서로의 탐지 공백을 어떻게 보완하는지** 확인하고자 했습니다.
